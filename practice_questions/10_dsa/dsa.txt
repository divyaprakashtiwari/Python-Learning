Question 1 (Easy):
--------------------------------------------------------------------------------
Problem Statement:
Write a Python program that designs an array manipulation utility `TwoPointerAlgorithms`
demonstrating classical two-pointer patterns with optimal O(N) time and O(1) auxiliary space:
1. Converging Two-Pointer Target Search:
   - `two_sum_sorted(nums: list[int], target: int) -> tuple[int, int] | None`:
     * Accepts a pre-sorted list of integers and a target sum.
     * Initializes pointer `left = 0` and pointer `right = len(nums) - 1`.
     * Evaluates `current_sum = nums[left] + nums[right]`:
       - If `current_sum == target`: returns 0-indexed indices `(left, right)`.
       - If `current_sum < target`: advances `left += 1` to increase sum.
       - If `current_sum > target`: retreats `right -= 1` to decrease sum.
     * Returns `None` if no pair exists.
2. Fast/Slow Two-Pointer In-Place Deduplication:
   - `remove_duplicates_sorted(nums: list[int]) -> int`:
     * Given a sorted list, removes duplicate entries in-place without allocating a new list.
     * Uses slow pointer `write_idx = 1` and fast pointer `read_idx = 1` to shift unique elements forward.
     * Returns `k`, the count of unique elements, such that `nums[:k]` contains all unique elements in sorted order.
3. In-Place Subarray Reversal:
   - `reverse_subarray(nums: list[int], start_idx: int, end_idx: int) -> None`:
     * Reverses elements between `start_idx` and `end_idx` in-place using simultaneous tuple assignment swapping.

Sample Input:
algo = TwoPointerAlgorithms()

# 1. Two-Sum Sorted Search
sorted_arr = [2, 7, 11, 15, 18, 22]
pair = algo.two_sum_sorted(sorted_arr, target=26)

# 2. In-place Deduplication
dups_arr = [1, 1, 2, 2, 3, 4, 4, 4, 5]
k = algo.remove_duplicates_sorted(dups_arr)
unique_slice = dups_arr[:k]

# 3. Subarray In-place Reversal
arr_to_rev = [10, 20, 30, 40, 50, 60]
algo.reverse_subarray(arr_to_rev, 1, 4)

Expected Output:
Two-Sum Target 26 Found: indices (2, 3) -> values (11 + 15 = 26)
Deduplication Result:
- Unique Count k = 5
- Deduplicated Prefix: [1, 2, 3, 4, 5]
Subarray Reversed (indices 1 to 4):
[10, 50, 40, 30, 20, 60]

Constraints & Edge Cases:
- `two_sum_sorted` must strictly operate in O(1) auxiliary memory (no hash set or dictionary lookups).
- For an empty list or single element, `remove_duplicates_sorted` must return `len(nums)` without modification.
- Subarray bounds must satisfy `0 <= start_idx <= end_idx < len(nums)`.

Question 2 (Easy):
--------------------------------------------------------------------------------
Problem Statement:
Write a Python program that designs an in-place sorting benchmark engine `SortingComparator`
implementing optimized Bubble Sort and Selection Sort alongside empirical execution metrics:
1. Optimized Bubble Sort (`bubble_sort(arr: list[int]) -> dict`):
   - Operates in-place on a copy of the input list.
   - Compares adjacent elements `(arr[j], arr[j+1])` and swaps if `arr[j] > arr[j+1]`.
   - Incorporates an early-exit optimization flag `swapped_in_pass`:
     * If an entire pass completes with zero swaps, breaks early, achieving O(N) best-case time complexity.
   - Measures and records:
     * `sorted_array`: Final sorted list.
     * `comparison_count`: Total element comparisons performed.
     * `swap_count`: Total swap operations performed.
     * `passes_completed`: Number of outer loops executed.
2. Selection Sort (`selection_sort(arr: list[int]) -> dict`):
   - Operates in-place on a copy of the input list.
   - For each index `i` from `0` to `n - 1`:
     * Scans the remaining unsorted suffix `[i...n-1]` to identify the index of the minimum element.
     * Swaps the found minimum element with `arr[i]` if the index differs.
   - Always performs exactly `n * (n - 1) // 2` comparisons, but minimizes write operations to at most `n - 1` swaps.
   - Measures and records `comparison_count` and `swap_count`.
3. Stability Demonstration:
   - Test both sorting algorithms using key-value pairs with duplicated keys:
     `[("TaskA", 2), ("TaskB", 1), ("TaskC", 2), ("TaskD", 1)]`.
   - Demonstrate that Bubble Sort preserves relative order of duplicate keys (stable),
     whereas Selection Sort's long-range swaps can disrupt relative ordering (unstable).

Sample Input:
comparator = SortingComparator()

test_arr = [64, 25, 12, 22, 11]
bubble_res = comparator.bubble_sort(test_arr)
selection_res = comparator.selection_sort(test_arr)

sorted_arr = [1, 2, 3, 4, 5]
bubble_best = comparator.bubble_sort(sorted_arr)

Expected Output:
Bubble Sort on [64, 25, 12, 22, 11]:
- Sorted: [11, 12, 22, 25, 64]
- Comparisons: 10
- Swaps: 8
- Passes: 4

Selection Sort on [64, 25, 12, 22, 11]:
- Sorted: [11, 12, 22, 25, 64]
- Comparisons: 10
- Swaps: 4

Bubble Sort Early-Exit on Already Sorted Array [1, 2, 3, 4, 5]:
- Comparisons: 4
- Swaps: 0
- Passes Completed: 1 (Terminated after 1st pass via early-exit flag)

Constraints & Edge Cases:
- Empty array `[]` and single-element array `[x]` must return immediately with 0 comparisons and 0 swaps.
- Sorting operations must not mutate the caller's original input list; operate on shallow copies.

Question 3 (Easy-Intermediate):
--------------------------------------------------------------------------------
Problem Statement:
Write a Python program that designs an algorithmic search toolkit `BinarySearchSuite`
implementing four fundamental logarithmic search patterns with strict O(log N) time complexity:
1. Exact Match Search (`search_exact(nums: list[int], target: int) -> int`):
   - Iterative binary search: evaluates `mid = low + (high - low) // 2`.
   - Returns 0-indexed position if found, or `-1` if absent.
2. Search Insert Position (`search_insert_position(nums: list[int], target: int) -> int`):
   - Determines the index where `target` is located, or the index where it should be inserted
     to preserve ascending sorted order (equivalent to `bisect_left`).
3. First and Last Occurrence Search (`find_occurrence_range(nums: list[int], target: int) -> tuple[int, int]`):
   - Given a sorted array with possible duplicate values (e.g. `[1, 2, 2, 2, 3, 5]`):
     * Runs modified binary search for the first (leftmost) occurrence:
       upon finding `nums[mid] == target`, saves index and continues searching left (`high = mid - 1`).
     * Runs modified binary search for the last (rightmost) occurrence:
       upon finding `nums[mid] == target`, saves index and continues searching right (`low = mid + 1`).
     * Returns `(first_idx, last_idx)` or `(-1, -1)` if target does not exist.
4. Search in Rotated Sorted Array (`search_rotated(nums: list[int], target: int) -> int`):
   - Given a distinct-element sorted array that was rotated around an unknown pivot
     (e.g., `[4, 5, 6, 7, 0, 1, 2]`):
     * Determines whether the left half `[low...mid]` or right half `[mid...high]` is sorted.
     * Checks if `target` falls within the boundaries of the sorted half to adjust search interval.
     * Completes in O(log N) time without linearly searching the array.

Sample Input:
suite = BinarySearchSuite()

# 1. Exact Search
idx1 = suite.search_exact([10, 20, 30, 40, 50], target=30)
idx_missing = suite.search_exact([10, 20, 30, 40, 50], target=25)

# 2. Insert Position
insert_pos = suite.search_insert_position([1, 3, 5, 6], target=4)

# 3. Duplicate Range
range_res = suite.find_occurrence_range([5, 7, 7, 8, 8, 8, 10], target=8)

# 4. Rotated Search
rotated_arr = [4, 5, 6, 7, 0, 1, 2]
rotated_idx = suite.search_rotated(rotated_arr, target=0)

Expected Output:
Exact Match Index (30): 2
Exact Match Missing (25): -1
Insert Position for 4 in [1, 3, 5, 6]: 2 (Inserts between 3 and 5)
Occurrence Range for 8: (3, 5)
Rotated Search for 0 in [4, 5, 6, 7, 0, 1, 2]: 4

Constraints & Edge Cases:
- All four algorithms must achieve strict O(log N) time complexity and O(1) auxiliary space.
- Empty array `[]` input must return `-1` for exact/rotated search, `0` for insert position, and `(-1, -1)` for occurrence range.

Question 4 (Easy-Intermediate):
--------------------------------------------------------------------------------
Problem Statement:
Write a Python program that designs a robust Stack data structure and applies it to real-world algorithmic problems:
1. Custom Stack Class (`ArrayStack[T]`):
   - Implements standard LIFO operations: `push(item: T) -> None`, `pop() -> T`, `peek() -> T`, `is_empty() -> bool`, and `__len__() -> int`.
   - Raises a custom exception `StackUnderflowError` if `pop()` or `peek()` is invoked on an empty stack.
   - Provides a clean string representation `__repr__` indicating stack depth and top item.
2. Balanced Delimiters Validator (`is_balanced(expression: str) -> tuple[bool, str]`):
   - Evaluates strings containing brackets `()`, `{}`, `[]` along with intervening text.
   - Uses a stack to ensure every opening bracket is matched by the correct closing delimiter in nested order.
   - Returns `(True, "Balanced")` or `(False, "<reason>")` describing the mismatch (e.g., unexpected closing bracket, unclosed opening bracket at end).
3. Constant-Time Min Stack (`MinStack`):
   - Implements `push(val: int)`, `pop() -> int`, `top() -> int`, and `get_min() -> int`.
   - Guarantees O(1) time complexity for ALL operations including `get_min()` by maintaining an auxiliary min-tracking stack.
4. Reverse Polish Notation (RPN / Postfix) Evaluator (`evaluate_postfix(tokens: list[str]) -> int`):
   - Evaluates arithmetic postfix expressions supporting `+`, `-`, `*`, `/` (truncating integer division toward zero).
   - Operates strictly with stack evaluation: operands pushed onto stack, binary operators pop two values and push result.

Sample Input:
# 1. Custom Stack
stack = ArrayStack[int]()
for v in [10, 20, 30]:
    stack.push(v)

popped_val = stack.pop()
top_val = stack.peek()

# 2. Balanced Delimiters
expr1 = "{[a + b] * (c - d)}"
expr2 = "([)]"
res1 = is_balanced(expr1)
res2 = is_balanced(expr2)

# 3. MinStack
min_s = MinStack()
min_s.push(5)
min_s.push(3)
min_s.push(7)
min_s.push(2)
m1 = min_s.get_min()
min_s.pop()  # pops 2
m2 = min_s.get_min()

# 4. RPN Evaluator
rpn_tokens = ["4", "13", "5", "/", "+"]  # 4 + (13 // 5) = 4 + 2 = 6
rpn_res = evaluate_postfix(rpn_tokens)

Expected Output:
ArrayStack Popped: 30
ArrayStack Top: 20, Current Size: 2
Expression 1 Balanced: (True, 'Balanced')
Expression 2 Balanced: (False, "Mismatched closing bracket ')' expecting ']'")
MinStack Initial Min: 2
MinStack After Popping 2 Min: 3
Postfix Evaluation Result: 6

Constraints & Edge Cases:
- `pop()` or `peek()` on empty `ArrayStack` or `MinStack` must raise `StackUnderflowError` with an informative error message.
- Postfix evaluation division must truncate toward zero (e.g., `-3 // 2` in Python gives `-2`, but `int(-3 / 2)` gives `-1`).
- Empty expression string `""` in `is_balanced` should evaluate to `(True, "Balanced")`.

Question 5 (Easy-Intermediate):
--------------------------------------------------------------------------------
Problem Statement:
Write a Python program that implements and benchmarks core Queue data structures and solves queue-based problems:
1. Fixed-Capacity Circular Queue (`CircularQueue[T]`):
   - Backed by a fixed-size list with `capacity` slots and pointer manipulation (`head`, `tail`, `count`).
   - Implements:
     * `enqueue(item: T) -> bool`: Inserts item at tail if not full; returns `True` on success, `False` if full (or raises `QueueOverflowError`).
     * `dequeue() -> T`: Removes and returns item at head; raises `QueueUnderflowError` if empty.
     * `front() -> T` and `rear() -> T`: Inspects boundaries without removal.
     * `is_empty() -> bool` and `is_full() -> bool`.
     * Calculates wrapping indices via modulo arithmetic: `(tail + 1) % capacity`.
2. Queue Implemented via Two Stacks (`TwoStackQueue[T]`):
   - Implements FIFO behavior using two separate stack instances (`in_stack` and `out_stack`).
   - `enqueue(item: T) -> None`: Pushes directly onto `in_stack` in O(1).
   - `dequeue() -> T`: Pops from `out_stack`. If `out_stack` is empty, transfers all elements from `in_stack` to `out_stack`, reversing their order to yield O(1) amortized time.
   - `peek() -> T` and `__len__() -> int`.
3. Hot Potato / Josephus Simulation (`josephus_circle(names: list[str], elimination_step: int) -> tuple[list[str], str]`):
   - Simulates circular potato passing where participants form a ring.
   - Using a queue, each pass dequeues a name and re-enqueues it to the rear.
   - At every `elimination_step`-th pass, the participant at the front is permanently eliminated and recorded.
   - Returns a tuple of `(elimination_order, winner)`.

Sample Input:
# 1. Circular Queue
cq = CircularQueue[int](capacity=3)
cq.enqueue(10)
cq.enqueue(20)
cq.enqueue(30)
is_full = cq.is_full()
d1 = cq.dequeue()
cq.enqueue(40)  # wraps around index 0

# 2. TwoStackQueue
tsq = TwoStackQueue[str]()
tsq.enqueue("A")
tsq.enqueue("B")
tsq.enqueue("C")
q_pop1 = tsq.dequeue()
tsq.enqueue("D")
q_pop2 = tsq.dequeue()

# 3. Josephus Ring Simulation
participants = ["Alice", "Bob", "Charlie", "David", "Emma"]
eliminated, survivor = josephus_circle(participants, elimination_step=3)

Expected Output:
Circular Queue Full: True
Circular Queue Dequeued: 10
Circular Queue Rear after 40: 40
TwoStackQueue Dequeued First: 'A'
TwoStackQueue Dequeued Second: 'B'
Josephus Elimination Order: ['Charlie', 'Alice', 'Emma', 'Bob']
Josephus Survivor: 'David'

Constraints & Edge Cases:
- Circular queue must prevent overwriting when full without resizing.
- Dequeue or peek on empty `TwoStackQueue` must raise `IndexError` or custom underflow error.
- If `elimination_step <= 0` or participant list is empty, `josephus_circle` must raise `ValueError`.

Question 6 (Intermediate):
--------------------------------------------------------------------------------
Problem Statement:
Write a Python program that designs a Singly Linked List and implements classical pointer-manipulation algorithms without using Python lists as internal storage:
1. `ListNode[T]` and `SinglyLinkedList[T]` classes:
   - `ListNode` has attributes `val: T` and `next: Optional[ListNode[T]]`.
   - `SinglyLinkedList` maintains a `head: Optional[ListNode[T]]` pointer and provides:
     * `append(val: T) -> None`: Inserts node at tail.
     * `prepend(val: T) -> None`: Inserts node at head in O(1).
     * `delete_value(val: T) -> bool`: Deletes first occurrence of node with value `val`; returns `True` if found and deleted, `False` otherwise.
     * `to_list() -> list[T]`: Traverses the list and returns values in a standard Python list.
2. In-Place Reversal:
   - `reverse()`: Reverses the linked list pointers in-place iteratively using three pointers (`prev`, `curr`, `next_node`) with O(N) time and O(1) space.
3. Middle Node Search (`find_middle() -> Optional[T]`):
   - Uses the fast & slow pointer technique (tortoise and hare) in a single pass.
   - Slow pointer advances 1 step while fast pointer advances 2 steps.
   - For even lengths, returns the second middle node.
4. Floyd's Cycle Detection and Entry Point (`detect_cycle() -> tuple[bool, Optional[T]]`):
   - Detects whether a linked list contains a loop using fast and slow pointers.
   - If a cycle is detected, resets one pointer to `head` and advances both pointers at equal speed to locate the exact node where the cycle begins.
   - Returns `(True, entry_val)` if cycle exists, or `(False, None)` otherwise.
5. Merge Two Sorted Lists (`merge_sorted_lists(l1: ListNode, l2: ListNode) -> ListNode`):
   - Merges two individually sorted linked list heads into a single sorted list by splicing existing nodes without creating new nodes.

Sample Input:
# 1 & 2. SLL and Reverse
sll = SinglyLinkedList[int]()
for x in [10, 20, 30, 40, 50]:
    sll.append(x)
mid_val = sll.find_middle()
sll.reverse()
reversed_list = sll.to_list()

# 3. Cycle Detection
cycle_sll = SinglyLinkedList[int]()
for x in [1, 2, 3, 4, 5]:
    cycle_sll.append(x)
# Artificially create cycle connecting node 5 back to node 3
node_3 = cycle_sll.head.next.next  # value 3
tail_node = node_3.next.next        # value 5
tail_node.next = node_3
has_cycle, cycle_entry = cycle_sll.detect_cycle()

# 4. Merge Two Sorted
l1 = build_linked_list([1, 3, 5])
l2 = build_linked_list([2, 4, 6])
merged_head = merge_sorted_lists(l1, l2)
merged_list = linked_list_to_list(merged_head)

Expected Output:
Middle Node of [10, 20, 30, 40, 50]: 30
Reversed Linked List: [50, 40, 30, 20, 10]
Cycle Detected: True, Cycle Entry Node Value: 3
Merged Sorted List: [1, 2, 3, 4, 5, 6]

Constraints & Edge Cases:
- Reversal and merging must be performed strictly in-place by updating pointer references; do not copy values into an array to rebuild nodes.
- Handled edge cases: empty list (`head is None`), single node, cycle pointing back to head (`node 5 -> node 1`).
