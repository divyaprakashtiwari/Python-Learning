Question 1 (Easy):
--------------------------------------------------------------------------------
Problem Statement:
Write a Python program that defines and tests a mathematical utility function
`calculate_cone_properties(radius: float, height: float)`:
1. Positional Parameters & Mathematical Computations:
   - Accept two positive floating-point numbers: `radius` and `height`.
   - Calculate the slant height using the Pythagorean theorem:
         slant_height = sqrt(radius**2 + height**2)
   - Calculate the lateral surface area:
         lateral_area = pi * radius * slant_height
   - Calculate the total surface area:
         total_area = pi * radius * (radius + slant_height)
   - Calculate the volume:
         volume = (1 / 3) * pi * (radius**2) * height
2. Return Values vs Side Effects:
   - The function must return a dictionary of computed metrics rounded to 2 decimal places,
     without performing any `print()` calls inside its body.
   - The caller must format and display the returned dictionary.
3. Input Validation:
   - If either `radius` or `height` is less than or equal to zero, raise a `ValueError`.

Sample Input:
radius = 3.0
height = 4.0

Expected Output:
Cone Properties for r=3.00, h=4.00:
- Slant Height: 5.00
- Lateral Surface Area: 47.12
- Total Surface Area: 75.40
- Volume: 37.70

Constraints & Edge Cases:
- Use `math.pi` and `math.sqrt` from Python's standard `math` module.
- Raise `ValueError("Dimensions must be strictly positive numbers")` if radius <= 0 or height <= 0.
- Ensure the function has no side-effects (does not mutate outer state or print directly).
