Question 1 (Easy):
--------------------------------------------------------------------------------
Problem Statement:
Write a Python program that designs an extensible rule-based FizzBuzz engine `ConfigurableFizzBuzz`:
1. Core FizzBuzz Specification:
   - For numbers from `1` to `N` (inclusive):
     * If divisible by 3, output "Fizz".
     * If divisible by 5, output "Buzz".
     * If divisible by both 3 and 5, output "FizzBuzz".
     * Otherwise, output the string representation of the number itself.
2. Extensible Rule Engine:
   - Instead of hardcoding 3 and 5, allow registering arbitrary divisor-to-word mappings
     (e.g., `{3: "Fizz", 5: "Buzz", 7: "Bazz"}`).
   - Rules must evaluate in specified order, concatenating matching tags (e.g., 105 is divisible by 3, 5, and 7 -> "FizzBuzzBazz").
3. Generator-Based Execution:
   - Provide a generator method `generate_sequence(start: int, stop: int) -> Generator[str, None, None]`
     that yields values lazily without storing the entire sequence in memory.
4. Summary Statistics:
   - Provide a method `frequency_summary(n: int) -> dict[str, int]` that returns counts of pure numbers vs tagged words produced.

Sample Input:
engine = ConfigurableFizzBuzz()
# Standard FizzBuzz for first 15 numbers
standard_results = list(engine.generate_sequence(1, 15))

# Custom rules: 2 -> "Bi", 3 -> "Tri", 5 -> "Quint"
custom_engine = ConfigurableFizzBuzz(rules={2: "Bi", 3: "Tri", 5: "Quint"})
custom_results = [custom_engine.evaluate(i) for i in [2, 3, 6, 15, 30, 7]]
stats = engine.frequency_summary(15)

Expected Output:
Standard 1 to 15:
['1', '2', 'Fizz', '4', 'Buzz', 'Fizz', '7', '8', 'Fizz', 'Buzz', '11', 'Fizz', '13', '14', 'FizzBuzz']
Custom Rule Evaluations:
- 2 -> 'Bi'
- 3 -> 'Tri'
- 6 -> 'BiTri'
- 15 -> 'TriQuint'
- 30 -> 'BiTriQuint'
- 7 -> '7'
Frequency Summary for 15:
{'numbers': 8, 'Fizz': 4, 'Buzz': 2, 'FizzBuzz': 1}

Constraints & Edge Cases:
- Divisors in rules must be non-zero positive integers (`divisor > 0`); raise `ValueError` on 0 or negative divisors.
- `start` must be less than or equal to `stop`; if `start > stop`, generator yields nothing.

Question 2 (Easy-Intermediate):
--------------------------------------------------------------------------------
Problem Statement:
Write a Python program that designs a comprehensive `PalindromeToolkit` implementing phrase validation, mathematical palindrome verification, almost-palindromes, and substring detection:
1. Alphanumeric Phrase Palindrome (`is_phrase_palindrome(s: str) -> bool`):
   - Validates whether string `s` reads identically forwards and backwards after stripping all non-alphanumeric characters and normalizing to lowercase.
   - Solves using two pointers moving inwards without allocating a new reversed string.
2. Numeric Palindrome Without String Conversion (`is_number_palindrome(num: int) -> bool`):
   - Determines whether integer `num` is palindromic using pure arithmetic operations (`% 10` and `// 10`).
   - Negative numbers return `False` immediately.
   - Reverses only the second half of the number to avoid integer overflow issues and compares with the first half.
3. Almost-Palindrome (Valid Palindrome II) (`can_be_palindrome_with_one_removal(s: str) -> tuple[bool, Optional[int]]`):
   - Checks if string `s` can become a palindrome by deleting at most one character.
   - Returns `(True, None)` if already palindrome, `(True, index)` indicating the index of the character that can be dropped, or `(False, None)`.
4. Longest Palindromic Substring (`longest_palindromic_substring(s: str) -> str`):
   - Finds the longest contiguous substring in `s` that is a palindrome.
   - Implements the Expand Around Center technique checking both odd-length centers `(i, i)` and even-length centers `(i, i+1)` in O(N^2) time and O(1) space.

Sample Input:
toolkit = PalindromeToolkit()

phrase_res = toolkit.is_phrase_palindrome("A man, a plan, a canal: Panama!")
phrase_res_false = toolkit.is_phrase_palindrome("race a car")

num_res_true = toolkit.is_number_palindrome(12321)
num_res_false = toolkit.is_number_palindrome(-121)

almost_res = toolkit.can_be_palindrome_with_one_removal("abca")  # deleting 'c' or 'b' makes it palindrome
longest_sub = toolkit.longest_palindromic_substring("babad")

Expected Output:
Phrase Palindrome "A man...": True
Phrase Palindrome "race a car": False
Number Palindrome 12321: True
Number Palindrome -121: False
Almost Palindrome "abca": (True, 2)  # removing character at index 2 ('c') leaves 'aba'
Longest Palindromic Substring of "babad": 'bab' (or 'aba')

Constraints & Edge Cases:
- String operations must handle empty strings and single characters as valid palindromes.
- `is_number_palindrome` must NOT convert the integer to `str(num)` or use any string slicing.
