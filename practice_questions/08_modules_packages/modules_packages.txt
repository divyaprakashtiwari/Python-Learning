Question 1 (Easy):
--------------------------------------------------------------------------------
Problem Statement:
Write a Python program that designs a dynamic module introspection and loader utility
`ModulePluginManager` demonstrating Python's module import system, `sys.modules` cache,
`sys.path` search order, and dynamic imports via `importlib`:
1. Search Path Registration:
   - `add_lookup_path(self, dir_path: str) -> bool`:
     * Resolves canonical directory path.
     * Checks if directory is already present in `sys.path`.
     * If absent, prepends it to index 0 of `sys.path` to give it top lookup priority and returns `True`.
     * If already present, returns `False`.
2. Dynamic Import & Cache Inspection:
   - `load_and_inspect_module(self, module_name: str) -> dict`:
     * Checks if `module_name` is already resident in `sys.modules`.
     * Dynamically imports the module using `importlib.import_module(module_name)`.
     * Inspects module attributes:
       - `name`: `mod.__name__`
       - `file_location`: `getattr(mod, "__file__", "BUILT_IN")`
       - `is_cached`: Boolean indicating whether it was already in `sys.modules` prior to the call.
       - `public_callables`: Alphabetically sorted list of all callable attributes that do not begin with an underscore `_`.
3. Dynamic Function Invocation:
   - `execute_plugin_function(self, module_name: str, function_name: str, *args, **kwargs) -> object`:
     * Loads the target module.
     * Uses `getattr(mod, function_name, None)` to look up the function.
     * If attribute does not exist or is not callable, raises `AttributeError(f"Function '{function_name}' not found in '{module_name}'")`.
     * Invokes and returns the function's execution result.

Sample Input:
manager = ModulePluginManager()
math_info = manager.load_and_inspect_module("math")
result_sqrt = manager.execute_plugin_function("math", "sqrt", 144)

# Re-inspecting cached module:
math_cached_info = manager.load_and_inspect_module("math")

Expected Output:
Module Introspection (math):
- Name: math
- File Location: BUILT_IN (or path to math extension DLL / so)
- Was Already Cached: True (standard built-in)
- Sample Public Callables: ['acos', 'asin', 'atan', 'ceil', 'cos', 'exp', 'floor', 'log', 'sin', 'sqrt', ...]
Dynamic Invocation (math.sqrt(144)): 12.0

Attempting invocation of missing function ('non_existent_fn'):
Caught Expected: AttributeError("Function 'non_existent_fn' not found in 'math'")

Constraints & Edge Cases:
- Attempting to dynamically import a non-existent module name must raise `ModuleNotFoundError`.
- `add_lookup_path` must reject non-existent directories by raising `NotADirectoryError`.

Question 2 (Easy-Intermediate):
--------------------------------------------------------------------------------
Problem Statement:
Write a Python program that designs a custom mathematical statistics module `custom_stats`
(or constructs a dynamic module instance via `types.ModuleType`) demonstrating module creation,
`__all__` export whitelisting, private internal encapsulation, and wildcard import mechanics:
1. Module Namespace Architecture:
   - Public Functions:
     * `calculate_mean(dataset: list[float]) -> float`: Computes arithmetic mean.
     * `calculate_median(dataset: list[float]) -> float`: Computes median of sorted elements.
     * `calculate_variance(dataset: list[float]) -> float`: Computes sample variance.
   - Private Helpers (Leading Underscore `_`):
     * `_validate_numeric_series(dataset: list) -> list[float]`: Validates non-empty numeric input.
     * `_sum_of_squared_deviations(dataset: list[float], mean_val: float) -> float`: Internal computation helper.
   - Module Constants:
     * `VERSION: str = "2.1.0"` (Public metadata)
     * `INTERNAL_PRECISION: int = 6` (Public unexported constant)
     * `_CALCULATION_CACHE: dict = {}` (Private module state)
2. Strict Export Control with `__all__`:
   - Define: `__all__ = ["calculate_mean", "calculate_median", "calculate_variance", "VERSION"]`.
   - Exclude `INTERNAL_PRECISION`, `_CALCULATION_CACHE`, and all `_` helper functions from `__all__`.
3. Wildcard Import (`from module import *`) Inspector:
   - Implement `simulate_wildcard_import(mod) -> list[str]`:
     * If `hasattr(mod, "__all__")`, returns a copy of `mod.__all__`.
     * If `__all__` is absent, returns all module attributes that do not start with `_`.
     * Verifies that `INTERNAL_PRECISION` is omitted from `import *`, yet remains accessible via
       direct qualified attribute access (`mod.INTERNAL_PRECISION`).

Sample Input:
mod = create_custom_stats_module()

mean_val = mod.calculate_mean([10.0, 20.0, 30.0, 40.0, 50.0])
exported_symbols = simulate_wildcard_import(mod)
direct_access_precision = mod.INTERNAL_PRECISION

Expected Output:
Mean Calculation: 30.0
Exported Symbols via `from custom_stats import *`:
['calculate_mean', 'calculate_median', 'calculate_variance', 'VERSION']

Encapsulation Verification:
- Is 'INTERNAL_PRECISION' in `__all__`? False
- Can 'INTERNAL_PRECISION' be accessed directly via module attribute? True (Value: 6)
- Are private functions ('_validate_numeric_series') in `__all__`? False

Constraints & Edge Cases:
- Functions must raise `ValueError("Dataset must be non-empty")` when given empty sequences.
- Modifying `__all__` at runtime must be respected by dynamic wildcard import simulators.

Question 3 (Easy-Intermediate):
--------------------------------------------------------------------------------
Problem Statement:
Write a Python program that designs a dual-mode cryptographic utility module `hasher_tool`
demonstrating the `if __name__ == "__main__":` idiom, distinguishing library import from
standalone CLI execution, and managing process exit codes via `sys.exit()`:
1. Reusable Library API (When Imported):
   - `hash_string(text: str, algorithm: str = "sha256") -> str`:
     * Validates `algorithm` against allowed set: `{"sha256", "sha512", "md5"}`.
       Raises `ValueError(f"Unsupported algorithm '{algorithm}'")` if not recognized.
     * Computes and returns the hex digest string using `hashlib`.
   - `hash_file_stream(filepath: str, algorithm: str = "sha256", chunk_size: int = 65536) -> str`:
     * Streams file in binary chunks and computes the cumulative hex digest.
2. CLI Dispatch Entry Point (`main(argv: list[str]) -> int`):
   - Uses `argparse.ArgumentParser` or raw `argv` parsing:
     * Accepts flags:
       - `--algo` (optional, default: `"sha256"`)
       - `--text` (string payload to hash)
       - `--file` (path to file to hash)
     * Enforces that either `--text` or `--file` must be specified, but not both.
     * On successful hash: prints result to stdout and returns integer exit code `0`.
     * On validation error or missing file: prints error to stderr and returns exit code `1` or `2`.
3. Standalone Execution Guard:
   - Implement the guard block:
     ```python
     if __name__ == "__main__":
         import sys
         sys.exit(main(sys.argv[1:]))
     ```
   - Prove that when this file is imported into another script (`import hasher_tool`),
     `__name__` evaluates to `"hasher_tool"` and the CLI parser does not trigger or read `sys.argv`.

Sample Input:
# Scenario A: Library Import Usage
import hasher_tool
h_val = hasher_tool.hash_string("Hello World", algorithm="sha256")

# Scenario B: CLI Execution (Simulated argv)
cli_exit_code = hasher_tool.main(["--algo", "sha256", "--text", "Hello World"])

# Scenario C: CLI Error Case (Missing Required Arguments)
cli_error_code = hasher_tool.main([])

Expected Output:
Library Import Call Result:
a591a6d40bf420404a011733cfb7b190d62c65bf0bcda32b57b277d9ad9f146e

CLI Execution Output:
SHA256: a591a6d40bf420404a011733cfb7b190d62c65bf0bcda32b57b277d9ad9f146e
CLI Exit Code: 0

CLI Missing Arguments Error:
Error: Exactly one of --text or --file must be specified.
CLI Exit Code: 2

Constraints & Edge Cases:
- Never invoke `sys.exit()` directly at the top level of module scope; `sys.exit()` must strictly live inside `main()` or under the `if __name__ == "__main__":` block.
- Module-level constants and functions must remain clean and side-effect free during standard `import`.

Question 4 (Easy-Intermediate):
--------------------------------------------------------------------------------
Problem Statement:
Write a Python program that designs an automated synthetic telemetry generator and bundle packager
`TelemetryBundleOrchestrator` coordinating six core Python Standard Library modules
(`math`, `random`, `os`, `sys`, `shutil`, and `json`):
1. Synthetic Generation (`random` & `math`):
   - `generate_sensor_readings(sample_size: int, seed: int = 101) -> list[dict]`:
     * Seeds `random.seed(seed)` for reproducible test generation.
     * Generates `sample_size` dictionaries containing:
       - `sensor_id`: randomly chosen from `["TEMP-01", "TEMP-02", "PRESSURE-01", "VIBRATION-01"]` via `random.choice()`.
       - `raw_reading`: generated via Gaussian distribution `random.gauss(mu=50.0, sigma=12.0)`.
       - `normalized_score`: computes standard score transformed via sigmoid: `1.0 / (1.0 + math.exp(-raw_reading / 25.0))` rounded to 4 decimals.
       - `is_alert`: boolean flag set to `True` if `raw_reading > 75.0` or `raw_reading < 25.0`.
2. Structured Export (`os` & `json`):
   - `export_dataset(records: list[dict], output_directory: str, filename: str = "telemetry.json") -> str`:
     * Uses `os.makedirs(output_directory, exist_ok=True)` to create target paths.
     * Serializes `records` to JSON using `json.dump(..., indent=2)`.
     * Returns the absolute path of the written file (`os.path.abspath`).
3. Compressed Archival Packaging (`shutil` & `os`):
   - `compress_bundle(directory_to_zip: str, archive_base_name: str, format: str = "zip") -> dict`:
     * Creates a compressed archive using `shutil.make_archive(archive_base_name, format, directory_to_zip)`.
     * Inspects resulting archive file size in bytes using `os.path.getsize(archive_path)`.
     * Returns `{"archive_path": archive_path, "size_bytes": size}`.
4. Runtime Environment Telemetry (`sys` & `os`):
   - `get_runtime_diagnostics() -> dict`:
     * Returns:
       `{"python_version": f"{sys.version_info.major}.{sys.version_info.minor}.{sys.version_info.micro}", "platform": sys.platform, "process_id": os.getpid(), "working_dir": os.getcwd()}`.

Sample Input:
orchestrator = TelemetryBundleOrchestrator()
readings = orchestrator.generate_sensor_readings(sample_size=5, seed=42)
filepath = orchestrator.export_dataset(readings, "./telemetry_staging", "metrics.json")
archive_meta = orchestrator.compress_bundle("./telemetry_staging", "./telemetry_backup", "zip")
env_info = orchestrator.get_runtime_diagnostics()

Expected Output:
Generated 5 sensor readings. Sample item 1:
{
  "sensor_id": "TEMP-01",
  "raw_reading": 53.07,
  "normalized_score": 0.8931,
  "is_alert": False
}
Exported file: /path/to/telemetry_staging/metrics.json
Archive Created: /path/to/telemetry_backup.zip (Size: ~750 bytes)
Environment Diagnostics:
- Python Version: 3.12.x
- Platform: win32 (or linux / darwin)
- Process ID: 12345

Constraints & Edge Cases:
- `sample_size <= 0` must raise `ValueError("Sample size must be strictly positive")`.
- Temporary staging directories and zip artifacts should be cleaned up appropriately during test teardown.
