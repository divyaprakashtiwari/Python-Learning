Problem Statement:
Write a Python program that designs a comprehensive `JSONHandler` utility demonstrating robust serialization, deserialization, and custom type encoding/decoding:
1. Standard Serialization & Deserialization:
   - `serialize_to_string(data: Any, indent: int = 2, sort_keys: bool = True) -> str`:
     * Serializes Python dictionaries and lists into formatted JSON strings.
   - `deserialize_from_string(json_str: str) -> Any`:
     * Parses JSON string into Python objects, catching `json.JSONDecodeError` and raising an informative custom exception `JSONParsingError`.
2. File I/O Operations:
   - `save_to_file(filepath: str, data: Any) -> None` using `json.dump` with UTF-8 encoding.
   - `load_from_file(filepath: str) -> Any` using `json.load`.
3. Custom Type Serialization (`CustomJSONEncoder`):
   - Standard `json.dumps()` fails with `TypeError: Object of type datetime is not JSON serializable`.
   - Subclass `json.JSONEncoder` to support:
     * `datetime.datetime` and `datetime.date` -> ISO-8601 formatted string (`YYYY-MM-DDTHH:MM:SS`).
     * `uuid.UUID` -> string representation.
     * `set` -> sorted list.
     * Custom dataclass or objects with `to_dict()` or `__dict__`.
4. Round-Trip Deserialization with `object_hook`:
   - `datetime_decoder(dct: dict) -> dict`: Automatically detects ISO datetime strings matching key patterns (e.g. `"created_at"`, `"timestamp"`) and reconstructs native `datetime` instances.

handler = JSONHandler()

raw_record = {

    "roles": {"admin", "developer"},
    "is_active": True,
    "metadata": None
}

json_output = handler.serialize_to_string(raw_record, indent=2)
recovered_obj = handler.deserialize_with_hook(json_output)

Expected Output:

  "created_at": "2026-10-26T14:30:00",
  "is_active": true,
  "metadata": null,
  "roles": [
    "admin",
    "developer"
  ],
  "user_id": "12345678-1234-5678-1234-567812345678",

}
Recovered created_at Type: <class 'datetime.datetime'>
Recovered user_id: '12345678-1234-5678-1234-567812345678'
Recovered roles: ['admin', 'developer']

Constraints & Edge Cases:
- Files must be opened with explicit `encoding="utf-8"` to prevent Windows platform encoding mismatches.
- Unsupported custom objects must raise `TypeError` via `super().default(o)` rather than silently converting to strings.

   - If `schema` is provided (e.g. `{"id": int, "salary": float, "is_active": bool}`), dynamically casts cell values into their specified Python types.

2. Flexible Writer with Custom Dialects (`write_csv(filepath: str, data: list[dict[str, Any]], fieldnames: list[str], delimiter: str = ',', quoting: int = csv.QUOTE_MINIMAL) -> None`):

   - Requires explicit `newline=''` on Windows file handles to prevent blank row duplication.
   - Automatically writes the header row.
   - Replaces missing dictionary keys with a specified `restval="N/A"`.
3. Column Aggregator (`aggregate_column(records: list[dict[str, Any]], column_name: str) -> dict[str, float]`):

4. Delimiter Sniffer & Auto-Detection:
   - Uses `csv.Sniffer` to inspect the first 1024 bytes of an unknown CSV file and automatically detect delimiter (comma, tab, pipe) and whether a header exists.

Problem Statement:

1. Database Setup & Connection Management:
   - Connects to SQLite database (file or in-memory `":memory:"`).
   - Enables foreign key constraint enforcement via `PRAGMA foreign_keys = ON;`.
   - Sets `conn.row_factory = sqlite3.Row` to allow accessing row columns both by index and by name.
2. DDL Schema Definition:
   - Creates `categories` table (`id INTEGER PRIMARY KEY AUTOINCREMENT`, `name TEXT UNIQUE NOT NULL`).
   - Creates `products` table:
     * `id INTEGER PRIMARY KEY AUTOINCREMENT`
     * `sku TEXT UNIQUE NOT NULL`
     * `name TEXT NOT NULL`
     * `price REAL NOT NULL CHECK(price >= 0)`
     * `stock INTEGER NOT NULL DEFAULT 0`
     * `category_id INTEGER REFERENCES categories(id) ON DELETE CASCADE`
     * `created_at TEXT NOT NULL DEFAULT (datetime('now'))`
3. Parameterized CRUD Operations:
   - `create_product(product: dict[str, Any]) -> int`: Inserts new product using parameterized placeholders (`?` or `:keys`) to strictly prevent SQL injection.
   - `get_product_by_id(product_id: int) -> Optional[dict[str, Any]]`: Returns product as dictionary or `None`.
   - `update_stock(product_id: int, quantity_delta: int) -> bool`: Updates inventory level within an atomic transaction.
   - `delete_product(product_id: int) -> bool`.
4. Batch Insertion and Transaction Rollback:
   - `batch_insert_products(products: list[dict[str, Any]]) -> int`:
     * Uses `cursor.executemany(...)` within an explicit transaction context manager (`with conn:`).
     * If any record violates constraints (e.g. negative price or duplicate SKU), automatically rolls back the entire batch, preserving database consistency.

updated_prod = repo.get_product_by_id(prod_id)

# 5. Batch Insert with Rollback Test

    {"sku": "SKU-MOU-001", "name": "Wireless Mouse", "price": 29.99, "stock": 50, "category_id": cat_id},
    {"sku": "SKU-LAP-001", "name": "Duplicate SKU Laptop", "price": 999.00, "stock": 5, "category_id": cat_id}  # Duplicate SKU!

     * Deduplicates records based on canonical `transaction_id` (keeps the newest by timestamp).
