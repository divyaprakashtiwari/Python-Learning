Question 1 (Easy):
--------------------------------------------------------------------------------
Problem Statement:
Write a Python program that determines an employee's annual tax liability and
effective tax rate based on progressive marginal tax brackets:
- Income up to $10,000: 0% tax
- Income from $10,001 to $40,000: 10% on the amount over $10,000
- Income from $40,001 to $85,000: $3,000 plus 20% on the amount over $40,000
- Income above $85,000: $12,000 plus 30% on the amount over $85,000
Use if/elif/else statements to calculate the exact tax owed, the net post-tax income,
and the effective overall tax rate (tax / gross income * 100).

Sample Input:
gross_income = 65000.00

Expected Output:
Gross Income: $65,000.00
Tax Bracket: 20% Marginal Bracket
Total Tax Owed: $8,000.00
Net Income: $57,000.00
Effective Tax Rate: 12.31%

Constraints & Edge Cases:
- Gross income cannot be negative (raise ValueError if negative).
- Gross income of $0 or within the 0% bracket must yield $0 tax and 0.00% effective rate.
- Display all monetary amounts to 2 decimal places.

Question 2 (Easy):
--------------------------------------------------------------------------------
Problem Statement:
Write a Python program that implements a loan underwriting decision engine using
nested conditional structures (nested if/elif/else):
1. Age Check: The applicant must be at least 18 and at most 65 years old.
   If outside this range, reject immediately with reason: "Age requirement not met".
2. Credit Score & Risk Check:
   - Credit score < 580: Reject with reason: "Poor credit rating".
   - Credit score between 580 and 669 (inclusive): "Fair Credit" — requires a qualified
     co-signer. If co-signer is present and has credit score >= 700, proceed to DTI check;
     otherwise reject with reason: "Qualified co-signer required".
   - Credit score >= 670: "Prime Credit" — proceed directly to DTI check.
3. Debt-to-Income (DTI) Ratio Check:
   - Calculate monthly income = annual_income / 12.
   - Calculate DTI ratio = (monthly_debt / monthly_income) * 100.
   - If DTI > 43.0%, reject with reason: "Debt-to-Income ratio exceeds limit".
   - If DTI <= 43.0%, APPROVE loan and assign interest rate:
     * Prime Credit: 5.25%
     * Fair Credit (with co-signer): 7.15%

Sample Input:
applicant = {
    "age": 29,
    "annual_income": 72000.0,
    "monthly_debt": 1800.0,
    "credit_score": 640,
    "has_cosigner": True,
    "cosigner_credit_score": 745
}

Expected Output:
Underwriting Decision: APPROVED
Credit Tier: Fair Credit (Co-signer Qualified)
Calculated DTI: 30.00%
Approved Base Interest Rate: 7.15%

Constraints & Edge Cases:
- Monthly debt and annual income must be positive; annual income cannot be zero (prevent ZeroDivisionError).
- Credit scores must be bounded between 300 and 850.
- All conditional paths must produce an explicit decision and reason.

Question 3 (Easy to Intermediate):
--------------------------------------------------------------------------------
Problem Statement:
Write a Python program that processes a discrete time-series of sensor temperature
readings using for loops and the range() function (testing start, stop, and step logic):
1. Running Reductions: Iterate through the readings using a for loop to compute the
   total sum, minimum value, and maximum value manually (without calling built-in
   sum(), min(), or max()).
2. Moving Window Average: Using range(len(readings) - window_size + 1), compute the
   k-point simple moving average (SMA) for window size k = 3, rounding each window
   mean to 2 decimal places.
3. Downsampling: Use range() with a step size of 2 to extract every alternating
   reading (subsampling at 50% frequency).
4. Backward Spike Detection: Iterate backwards from the end of the list using
   range(len(readings) - 1, -1, -1) to locate the index and value of the most recent
   reading that exceeded a threshold of 30.0 degrees Celsius.

Sample Input:
temperatures = [21.5, 23.0, 28.5, 31.2, 29.8, 33.4, 27.1, 24.0]
window_size = 3
spike_threshold = 30.0

Expected Output:
Manual Reductions: Sum = 218.50, Min = 21.50, Max = 33.40, Average = 27.31
3-Point Moving Averages: [24.33, 27.57, 29.83, 31.47, 30.10, 28.17]
Downsampled (Step 2): [21.5, 28.5, 29.8, 27.1]
Most Recent Spike Moving Backwards: Index 5 with value 33.40 C

Constraints & Edge Cases:
- Do not use NumPy or pandas; use standard Python loops and lists.
- If no reading exceeds the spike threshold, report "No spike detected".
- Temperature list must contain at least k elements for moving average calculation.

Question 4 (Easy to Intermediate):
--------------------------------------------------------------------------------
Problem Statement:
Write a Python program that uses a while loop to simulate and analyze the Collatz
Conjecture (the 3n + 1 problem) for a given starting positive integer:
1. While the current value of n is strictly greater than 1:
   - If n is even: divide n by 2 (using integer floor division //).
   - If n is odd: multiply n by 3 and add 1 (n = 3 * n + 1).
2. During iteration, record:
   - The complete sequence of values generated.
   - The total number of steps (stopping time) required to reach 1.
   - The peak (maximum) integer value encountered anywhere in the trajectory.
3. Guard against infinite looping by maintaining a safety counter `max_iterations = 5000`;
   terminate the loop and report an error if this threshold is exceeded.

Sample Input:
starting_number = 27

Expected Output:
Starting Value: 27
Total Stopping Time (Steps): 111
Peak Trajectory Value: 9232
First 5 Values: [27, 82, 41, 124, 62]
Last 5 Values: [8, 4, 2, 1]
Safety Limit Triggered: False

Constraints & Edge Cases:
- Starting number must be an integer >= 1 (raise ValueError for n < 1).
- If starting_number is 1, stopping time is 0 steps and peak is 1.
- Use integer arithmetic exclusively to avoid precision loss on large peaks.
