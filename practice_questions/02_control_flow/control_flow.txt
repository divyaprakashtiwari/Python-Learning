Question 1 (Easy):
--------------------------------------------------------------------------------
Problem Statement:
Write a Python program that determines an employee's annual tax liability and
effective tax rate based on progressive marginal tax brackets:
- Income up to $10,000: 0% tax
- Income from $10,001 to $40,000: 10% on the amount over $10,000
- Income from $40,001 to $85,000: $3,000 plus 20% on the amount over $40,000
- Income above $85,000: $12,000 plus 30% on the amount over $85,000
Use if/elif/else statements to calculate the exact tax owed, the net post-tax income,
and the effective overall tax rate (tax / gross income * 100).

Sample Input:
gross_income = 65000.00

Expected Output:
Gross Income: $65,000.00
Tax Bracket: 20% Marginal Bracket
Total Tax Owed: $8,000.00
Net Income: $57,000.00
Effective Tax Rate: 12.31%

Constraints & Edge Cases:
- Gross income cannot be negative (raise ValueError if negative).
- Gross income of $0 or within the 0% bracket must yield $0 tax and 0.00% effective rate.
- Display all monetary amounts to 2 decimal places.

Question 2 (Easy):
--------------------------------------------------------------------------------
Problem Statement:
Write a Python program that implements a loan underwriting decision engine using
nested conditional structures (nested if/elif/else):
1. Age Check: The applicant must be at least 18 and at most 65 years old.
   If outside this range, reject immediately with reason: "Age requirement not met".
2. Credit Score & Risk Check:
   - Credit score < 580: Reject with reason: "Poor credit rating".
   - Credit score between 580 and 669 (inclusive): "Fair Credit" — requires a qualified
     co-signer. If co-signer is present and has credit score >= 700, proceed to DTI check;
     otherwise reject with reason: "Qualified co-signer required".
   - Credit score >= 670: "Prime Credit" — proceed directly to DTI check.
3. Debt-to-Income (DTI) Ratio Check:
   - Calculate monthly income = annual_income / 12.
   - Calculate DTI ratio = (monthly_debt / monthly_income) * 100.
   - If DTI > 43.0%, reject with reason: "Debt-to-Income ratio exceeds limit".
   - If DTI <= 43.0%, APPROVE loan and assign interest rate:
     * Prime Credit: 5.25%
     * Fair Credit (with co-signer): 7.15%

Sample Input:
applicant = {
    "age": 29,
    "annual_income": 72000.0,
    "monthly_debt": 1800.0,
    "credit_score": 640,
    "has_cosigner": True,
    "cosigner_credit_score": 745
}

Expected Output:
Underwriting Decision: APPROVED
Credit Tier: Fair Credit (Co-signer Qualified)
Calculated DTI: 30.00%
Approved Base Interest Rate: 7.15%

Constraints & Edge Cases:
- Monthly debt and annual income must be positive; annual income cannot be zero (prevent ZeroDivisionError).
- Credit scores must be bounded between 300 and 850.
- All conditional paths must produce an explicit decision and reason.

Problem Statement:

4. Backward Spike Detection: Iterate backwards from the end of the list using
   range(len(readings) - 1, -1, -1) to locate the index and value of the most recent

Downsampled (Step 2): [21.5, 28.5, 29.8, 27.1]
Most Recent Spike Moving Backwards: Index 5 with value 33.40 C

Constraints & Edge Cases:
- Do not use NumPy or pandas; use standard Python loops and lists.
- If no reading exceeds the spike threshold, report "No spike detected".
- Temperature list must contain at least k elements for moving average calculation.

--------------------------------------------------------------------------------
Problem Statement:

using break and continue statements:
1. Iterate over a sequential list of packet dictionaries containing:
   `packet_id`, `source_ip`, `payload_bytes`, `status_code`, and `is_malicious`.
2. Apply the following control flow rules:
   - If `source_ip` is present in a pre-configured `blocked_ips` set: increment
     a `blocked_count` counter and invoke `continue` immediately to bypass inspection.
   - If `status_code == 200` and `payload_bytes == 0` (empty health ping): invoke
     `continue` to skip logging and processing without incrementing counters.
   - If `is_malicious is True`: log a security alert and immediately invoke `break`
     to shut down the ingestion pipeline to prevent compromise.
   - For all other benign packets: accumulate the total bytes ingested into `total_bytes`
     and increment `valid_packets_processed`.
3. After the loop terminates, report whether ingestion completed cleanly or halted
   due to a security breach, along with summary counts.

blocked_ips = {"198.51.100.12", "203.0.113.5"}
packets = [

Problem Statement:
Write a Python program that utilizes single-line conditional (ternary) expressions
(`x if condition else y`) to perform data clamping, status mapping, and resilient
fallback resolution:
1. Numerical Signal Clamping:
   - Given a sensor voltage signal `v` and bounds `[min_bound, max_bound]`:
   - Using a nested ternary expression, clamp `v` so that if `v < min_bound` it evaluates
     to `min_bound`, if `v > max_bound` it evaluates to `max_bound`, and otherwise retains `v`.
2. Telemetry Severity Classifier:
   - Given an integer error code:
   - Use a chained ternary expression to assign an operational status string:
     * code == 0 -> "NOMINAL"
     * 1 <= code <= 99 -> "INFO"
     * 100 <= code <= 299 -> "WARNING"
     * code >= 300 -> "CRITICAL"
     * code < 0 -> "CORRUPT_SIGNAL"
3. Resilient Endpoint Resolver:
   - Given three candidate endpoints: `primary_endpoint`, `backup_endpoint`, and a constant `DEFAULT_HOST`:
   - Using inline ternary selection, select the first non-empty, valid string endpoint.
4. Demonstrate that the false branch of a ternary expression is not evaluated when the
   condition is true by including an expression that would otherwise raise a ZeroDivisionError
   in the unreached branch.

Sample Input:
signal_voltage = 14.85
min_bound = 0.0
max_bound = 12.0
error_code = 142
primary_endpoint = None
backup_endpoint = "https://backup-api.internal"
DEFAULT_HOST = "https://fallback.internal"

Expected Output:
Raw Voltage: 14.85 V -> Clamped Voltage: 12.00 V
Error Code: 142 -> Operational Status: "WARNING"
Resolved Endpoint: "https://backup-api.internal"
Safe Division Evaluation: 100.0 (Unreached division by zero avoided via short-circuit)

Constraints & Edge Cases:
- Clamping and classification must be implemented via conditional expressions
  (`a if cond else b`), not multi-line if/elif blocks.
- Endpoints can be None, empty string "", or valid URL strings.
